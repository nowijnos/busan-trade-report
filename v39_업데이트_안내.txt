부산지역 수출입동향 웹 자동작성 v39

확인한 문제: 이전 v36~v38은 Render의 실행 중 글꼴 설정에 영향을 받음.
해결 방식: 차트에 들어가는 모든 문자(한글, 연월, 숫자, %, 기호)를
미리 준비한 픽셀 글자 아틀라스(PNG)로 직접 합성함.
Render에는 한글 폰트 설치가 필요하지 않으며, 글꼴 파일은 배포하지 않음.

수정: engine.py의 그래프 이미지 생성 경로, 신규 chart_raster_text.py,
      chart_assets/glyph_atlas.png / glyph_metrics.json, server.py의 버전 표기.
유지: 엑셀 자료 입력 규칙, 수출/수입 데이터·차트 종류,
      기존 표 1~7, 본문, HWPX 표/페이지 구조, 크롬 수집 도우미.

GitHub 저장소 루트에 ZIP 안 파일/폴더 전부 업로드 및 commit.
Render 배포 성공 후 주소 뒤 /health 에서
'v39-rasterized-chart-text' 표시 확인.
이전 생성 HWPX는 변하지 않으므로 v39로 다시 보고서를 다운로드.

※ 로컬에서는 실제 엑셀의 두 시트 데이터를 사용해 차트 2개를 출력 검증.
Render에서 실제 다운로드한 HWPX의 화면은 별도 최종 확인이 필요함.
