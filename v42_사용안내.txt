부산 수출입동향 분석실 v42 — 신규 기능 (정기보고서 v41 유지)
==========================================================

[설치]
1. busan_site_v42_analysis_studio.zip 압축을 풀어 GitHub 루트에 파일/폴더 전체 업로드합니다.
2. Render 배포 후 /health 에 version: v42-analysis-studio 확인.
3. 크롬 확장관리(chrome://extensions)에서 기존 보고서 도우미를 제거하고
   busan_chrome_helper_v42_analysis_studio.zip을 압축 해제해 busan_report_helper_v42 폴더를 로드합니다.
4. 웹사이트 처음 화면 '수출입동향 분석실' 또는 /analysis로 진입합니다.

[사용]
1. 기간(시작월~종료월), 부산/타 지역, 수출/수입, MTI/HS 품목분류, 국가를 클릭/검색으로 선택합니다.
2. 확장 도우미와 연결된 경우 'K-Stat에 조회 조건 적용'을 선택합니다.
   현재 검증된 자동 입력 범위는 부산(60) 또는 전체, MTI 2/3/4단위,
   연월(종료월 1개), 당월/누계, 수출/수입 정렬, 국가 코드입니다.
   실제 지역/국가 팝업 반영과 품목 키워드는 사용자가 K-Stat 공식 화면에서 확인/선택합니다.
   다른 지역, HS/HSK, 한 번에 여러 국가/월은 K-Stat에서 순차적으로 조회해 주세요.
3. K-Stat 공식 화면에서 실제 결과표 검증 후 XLS/XLSX를 다운로드합니다.
4. /analysis에 파일을 업로드하거나, 국가별 데이터는 제공된 CSV 양식으로 업로드합니다.
5. 국가/품목/월 비교 분석, 원인 단서 확인 후 관련 뉴스 검색 버튼을 클릭합니다.
6. 확인한 기사 제목, 날짜, 링크 및 요약을 직접 등록합니다.
7. '별도 보고서'에서 통계 사실과 추가 검증 가설을 구분하여 입력한 뒤 DOCX 다운로드 또는 PDF 인쇄.

[정확도/한계]
- K-Stat 비공개 API를 임의로 사용하지 않습니다. 사이트에서 조회 및 엑셀 다운로드 절차가 필요합니다.
- 품목 키워드 후보 사전은 기존 원본의 일부 코드입니다. 완전한 MTI/HS 코드북이 아닙니다.
- K-Stat 엑셀 A2 '지역:전국' 표기는 사이트 표시와 다를 수 있으므로 지역·합계 재검증이 필요합니다.
- 국가 전체 품목표에서 국가별 비중, 순위, 수출 물량 이동은 추정하지 않습니다.
- 당월과 누계, MTI2/MTI4/HSK 등 서로 다른 품목단위를 임의 합산하지 않습니다.
- 비교 기간 자료가 없으면 미확인으로 남기며 통계 없는 숫자를 만들지 않습니다.
- 뉴스 검색은 네이버뉴스/구글뉴스의 검색결과를 열어 줍니다. 본문 자동 크롤링·기사 사실검증을 하지 않습니다.
- 뉴스 요지는 사용자가 확인 후 입력한 메모만 별도 보고서에 반영합니다.
- 분석실은 신규 기능. 기존 보고서 9개 다운로드/생성 코드를 바꾸지 않았습니다.

[검증]
- 기존 실제 2026-10 K-Stat XLS 2개 148 품목코드/금액 파싱 통과
- /health, /, /guide, /report, /analysis, /analysis/catalog, /analysis/csv-template 및 XLS ingest, DOCX export HTTP 테스트 통과
- Chromium 정적 UI: 클릭/검색·국가 선택·차트·표·뉴스 링크 4건 생성 테스트 통과
- Word 보고서 render_docx.py 한글 렌더링 1페이지 확인
- K-Stat 실서비스 Chrome 확장 연속조회/실제 배포 검증은 아직 진행하지 못함
