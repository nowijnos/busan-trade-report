부산 수출입동향 자동화 v40 / 수집 단계 검증 강화

[배포]
1. 이 ZIP을 압축 해제하여 GitHub 저장소 파일 전체를 교체합니다.
2. Render에 배포되면 /health 주소에서 'v40-kstat-result-audit' 확인. 웹사이트 메인 화면의 ‘도우미 다운로드’로 v40을 받습니다.
3. Chrome > 확장 프로그램 > 확장 프로그램 관리 > 기존 부산 도우미를 제거합니다.
4. 새 v40 ZIP 압축 해제 > 개발자 모드 > 압축 해제된 확장프로그램 로드 > busan_report_helper_v40 폴더 선택
5. 열어 둔 K-Stat 탭을 새로고침한 다음 새 작업을 시작합니다.

[왜 수정했나]
기존 v32는 조회 버튼 실행 후 결과가 갱신되었는지 보장하지 않고, 내려받기가 끝나면 다음 단계로 이동했습니다.
이제 조회표에서 MTI2/MTI3 코드 자릿수/유효한 품목 행/이전 결과와의 변화를 확인하지 못하면 다운로드 단계 진행을 중단합니다.

[한계]
현재 수정은 코드/모의 화면을 통한 로컬 검증입니다. K-Stat 실사이트 DOM 구조의 변경이나 브라우저에서 실제 9건 연속 수집은 아직 검증하지 않았습니다. 오인 방지를 위해 불확실할 때는 다음 단계로 넘기지 않도록 했습니다.
한글 그래프 v39, 표/문장/HWPX 서식은 그대로 유지했습니다.
