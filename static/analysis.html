이상 징후 발견 → K-Stat 조사 → 국가·품목별 비교 → 뉴스 확인 → 독립 분석보고서 작성

1. K-Stat 상세조회

코드를 외울 필요 없이 콤보상자에서 선택하세요. 품목 후보 목록은 일부 공식 자료의 품목명이며, 전체 코드 검색은 K-Stat에서 최종 확인해야 합니다.

검색어를 입력하거나 후보에서 선택
아무것도 선택하지 않으면 전체 국가 기준
실제 K-Stat 자료 조회 방법
확장 도우미가 설치되어 있으면 선택한 지역·연월·국가·MTI 조건 일부를 K-Stat에 채울 수 있어요. 단, K-Stat 자체 품목 키워드·HS 코드 선택은 공식 검색창에서 최종 선택해야 하며, 화면에서 조회 실행과 결과 확인이 필요합니다. 자동 API 연결이나 자동 수치 취득을 뜻하지 않습니다.
K-Stat 직접 열기

2. 조회한 자료 불러오기

K-Stat에서 받은 .xls/.xlsx 파일 또는 국가별 월간 실적 CSV를 선택해. 파일을 받아야 수치 비교가 가능해. 데이터는 서버 메모리에서 파싱되고 브라우저 분석 상태로 반환돼.

국가별 분석 CSV 양식 받기

2. 수출입 변화 분석

업로드된 관측값만 사용합니다. '전체 국가' 품목표는 국가별 비중·순위로 분해하지 않습니다. 월별 추이는 당월 자료만 연결합니다.

아직 분석할 자료가 없습니다. 첫 화면에서 실제 K-Stat 엑셀을 불러와 주세요.
연월국가품목기준실적(달러)전년 동월/같은 기간증감액출처

3. 관련 기사 검색·근거 메모

통계에서 원인을 확정할 수는 없어. 검색어를 만들어 뉴스 포털을 열고, 직접 확인한 기사만 보고서 근거로 추가하는 방식이야.

검증한 기사 등록

4. 별도 분석보고서 만들기

정해진 양식 없는 독립 보고서. 통계표, 조사 내용, 기사 요지, 확인되지 않은 가설과 출처를 나누어 DOCX로 저장할 수 있어.

보고서 수록 정보
현재 조회조건 · 실제 업로드 자료의 통계표(최대 35행) · 분석 메모 · 직접 등록한 기사 및 링크 · 가설과 확인 필요 사항 · 원본 파일명. 통계에 없는 원인은 자동 생성하지 않아.

개인정보·기사 본문 무단수집 없음. 통계 조건은 실제 K-Stat 조회파일과 재확인하세요. 원자료 없는 값과 기사 원인은 임의로 작성하지 않습니다.
