01 품목의 국가별 실적 확인

품목코드와 연월을 선택해 K-Stat의 지자체 수출입 · 국가별 화면으로 이동하고, 조회 실행까지 시도합니다. 엑셀 다운로드는 필요 없어요. 단위는 US$, %로 맞춥니다.

목록에서 품목을 선택하거나 품목코드를 직접 입력해 줘.
공식 K-Stat 직접 열기

자동 이동·입력·조회는 설치된 기존 크롬 도우미의 내부 연결 기능을 사용합니다. 도우미 화면에는 분석실 메뉴가 표시되지 않아요. K-Stat 로그인 및 화면 구조에 따라 조회가 제한될 수 있고, 결과가 확인되지 않으면 완료로 표시하지 않습니다. 조회 조건은 수출입 금액 내림차순 · 단위 US$, %로 자동 설정합니다. 지역코드 60을 입력해도 K-Stat 자체 지역명이 '전국'으로 남을 수 있으므로, 실제 부산 적용 여부를 확인하지 못하면 완료라고 안내하지 않습니다.

02 왜 변했을까? 관련 뉴스 찾기

국가별 순위에서 변화를 발견했다면 국가와 변화 유형을 고른 뒤 뉴스 검색을 눌러봐. 품목은 위에서 선택한 내용을 자동 사용해.

03 조사 메모 및 별도 분석보고서

K-Stat에서 확인한 금액과 국가별 비중 등 실제 조회 결과를 정리해. 사이트가 통계값을 자동으로 가져왔다고 주장하지 않아.

보고서에는 조회 조건·분석 메모·확인한 뉴스 제목·링크·요약·추가 확인사항이 포함돼. 기사와 통계 내용을 자동으로 사실 확정하지 않습니다.

자료 출처: K-Stat 조회 결과(사용자 확인) / 기사 원문 링크(사용자 기록). 이 도구는 공공 페이지를 대신해 자료를 수집하지 않으며, 서버에 K-Stat 로그인 정보를 전달하지 않습니다.
