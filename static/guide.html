처음부터 따라 하는 사용방법

한 번만 설치하면, 다음부터는 K-Stat 파일 6개를 순서대로 받으면 됩니다.

중요! 반드시 구글 크롬(Chrome)으로 열어 주세요.
⬇ 크롬 도우미 설치 파일 받기 (ZIP)

※ 크롬 보안 정책상 웹사이트에서 확장 프로그램을 자동 설치할 수 없습니다. 아래 첫 두 그림처럼 한 번만 설치해 주세요.

1

크롬 도우미 설치

아래 파란 버튼으로 ZIP을 받고 압축을 풀어 주세요.

화면 안내 그림 · 클릭할 곳을 빨간 테두리로 표시했습니다.
2

크롬 확장 프로그램에 추가

주소창에 chrome://extensions 입력 → 개발자 모드 켜기 → 폴더 선택

화면 안내 그림 · 클릭할 곳을 빨간 테두리로 표시했습니다.
3

K-Stat 열기

도우미에서 맨 위 [K-Stat 열기]를 누르세요.

화면 안내 그림 · 클릭할 곳을 빨간 테두리로 표시했습니다.
4

보고서 연월 입력·조회

도우미에 연도와 월을 입력하고 [새 작업 시작]을 누르세요.

화면 안내 그림 · 클릭할 곳을 빨간 테두리로 표시했습니다.
5

결과 확인·엑셀다운 6번

지역 부산(60), 국가·기간·금액순위를 확인한 뒤 체크하고 다운로드하세요.

화면 안내 그림 · 클릭할 곳을 빨간 테두리로 표시했습니다.
6

엑셀 6개 직접 선택

6개 다운로드가 끝나면 [보고서 사이트로 가져오기] → 6개 파일 선택

화면 안내 그림 · 클릭할 곳을 빨간 테두리로 표시했습니다.
7

본부 엑셀 1개 추가

보고서 작성 페이지에 자동으로 채워진 6개를 확인하고, 본부 파일을 선택하세요.

화면 안내 그림 · 클릭할 곳을 빨간 테두리로 표시했습니다.
8

한글 보고서 다운로드

[한글 보고서 생성하기] → [한글 파일 다운로드]를 누르세요.

화면 안내 그림 · 클릭할 곳을 빨간 테두리로 표시했습니다.
파일 전달이 안 될 때

보고서 사이트에 로그인했는지 확인하고, 크롬 도우미의 [보고서 사이트로 가져오기]를 다시 누르세요. 파일이 정상적으로 전달되면 보고서 작성 화면에 “6개 파일 선택 완료”가 표시됩니다.

주의: K-Stat에 ‘전국’이라는 예전 표기가 남을 수 있습니다. 도우미가 표시하는 부산(60) 코드와 실제 조회 결과를 반드시 확인해 주세요.

② 보고서 작성 페이지로 이동

계정·비밀번호·로그인 쿠키는 크롬 도우미에 입력하지 않습니다. 파일은 사용자가 직접 선택한 뒤 보고서 사이트로 전달됩니다.
