구글 크롬(Chrome) 전용
처음 사용하는 분만 먼저 도우미를 설치하세요. 이미 설치했다면 아래 1번부터 시작하면 됩니다.
부산 수출입동향 보고서 도우미 다운로드 ↓

처음 1회 설치만 먼저 해주세요

아래 두 단계만 하면 설치가 끝납니다. 개발자 모드는 오른쪽 위, 압축해제된 확장 프로그램 로드는 왼쪽 위에 있어요.

설치 A
  • ZIP 압축 해제
  • 크롬 확장 프로그램 열기
  • 오른쪽 위 개발자 모드 켜기
설치 B
  • 왼쪽 위 압축해제된 확장 프로그램 로드 클릭
  • 압축 푼 도우미 폴더 선택
  • 아래 화면처럼 도우미 아이콘 확인
링크가 열리지 않으면 chrome://extensions 후 주소창에 붙여넣으세요.
1

K-Stat 열기 → 연월 입력 → 자동 조회

도우미 맨 위에서 K-Stat 열기를 누른 다음, 연도·월을 입력하고 새 작업 시작·자동 조회를 누르세요.

설치가 이미 끝난 분은 여기서부터 시작하면 됩니다.
2

지역·기간·정렬 확인

아래 항목과 실제 조회표를 비교한 뒤 체크하세요.

지역코드60 · 부산
국가수출·수입 MTI2: 전체 / 중국 MTI3: CN
조회기간당월 / 금년누계 / 전년누계
정렬수출금액 또는 수입금액 · 내림차순
K-Stat에 지역코드 60을 입력하면 화면의 ‘전국’ 글자를 ‘부산’으로 보정합니다. 보정이 불가능하면 지역칸 아래에 안내문이 나옵니다.
3

체크 → 엑셀다운 × 9회

결과를 확인해 체크하고 엑셀다운을 누르세요. 다음 조건은 자동 조회됩니다.

수출 MTI2 3회 + 수입 MTI2 3회 + 중국 수입 MTI3 3회
4

9개 엑셀 선택해서 사이트로 보내기

보고서 사이트로 가져오기 → 다운로드한 엑셀 9개 선택 → 전달

폴더 권한을 열 필요는 없습니다.
5

본부 엑셀 1개 추가

보고서 작성에서 본부 엑셀을 선택하세요. K-Stat 9개는 이미 전달된 상태입니다.

본부 엑셀 1개 + K-Stat 9개 확인
6

한글 보고서 생성하기

한글 보고서 생성하기를 클릭해 HWPX를 받으세요. 필요 시 검증 항목만 열어 확인합니다.

틀린 조건이나 필수 품목 누락이 있으면 이유를 표시합니다.

예시 화면과 크롬 버전에 따라 버튼 위치가 조금 다를 수 있습니다. K-Stat 지역코드가 60이면 부산입니다.   보고서 작성 바로가기
