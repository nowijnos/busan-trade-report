사용방법

도우미 설치가 끝난 분은 아래 1번부터 순서대로 진행하세요.

진행 순서: K-Stat 열기 → 조회 확인·다운로드 9회 → 사이트에 엑셀 전달 → 보고서 작성
1

K-Stat 열기 → 연월 입력 → 자동 조회

도우미 맨 위에서 K-Stat 열기 → 보고서 연도·월 입력 → 새 작업 시작·자동 조회 순서로 눌러주세요.

2

지역·기간·정렬 확인

아래 조건과 실제 K-Stat 조회표가 일치하는지 확인하세요.

지역부산 · 지역코드 60
국가수출·수입 MTI2는 전체 / 중국 MTI3은 CN
기간당월 / 금년 누계 / 전년 누계
정렬수출금액 또는 수입금액 · 내림차순
K-Stat의 ‘전국’ 글자가 남더라도 지역코드 60과 조회 실적을 확인하세요.
3

조건 확인 체크 → 엑셀다운 × 9회

조회 결과를 확인한 뒤 체크박스 선택 → 엑셀다운. 다음 조건은 자동으로 조회됩니다.

부산 수출 MTI2 3회 + 부산 수입 MTI2 3회 + 중국 수입 MTI3 3회
4

엑셀 9개를 보고서 사이트로 보내기

도우미의 보고서 사이트로 가져오기 → 다운로드한 엑셀 9개 선택 → 전달

파일을 역순으로 선택해도 내부 조회조건으로 분류합니다.
5

본부 엑셀 1개 선택

보고서 작성 화면에 본부 엑셀 1개를 선택하고, K-Stat 파일 9개가 전달됐는지 확인하세요.

본부 엑셀 1개와 K-Stat 9개를 모두 확인
6

한글 보고서 생성

한글 보고서 생성하기 클릭 → HWPX 다운로드. 오류가 발생할 때만 상세 내용을 열어보세요.

완성된 보고서의 통계와 페이지 배치는 최종 확인이 필요합니다.

도우미 설치가 아직 안 된 경우에는 첫 화면에서 처음 1회만 설치하면 됩니다.   보고서 작성 바로가기
