그림으로 보는 사용방법

설치는 처음 한 번만 하면 돼요. 다음부터는 ③번부터 시작하세요.

먼저 확인: 구글 크롬(Chrome)에서만 사용 가능합니다.크롬 도우미 다운로드 (ZIP)
1

확장 프로그램 설치 (처음 1회)

ZIP 압축 해제 → 크롬 확장 프로그램 열기 → 오른쪽 위 개발자 모드 켜기 → 압축해제된 확장 프로그램 로드

링크가 열리지 않으면 chrome://extensions 후 크롬 주소창에 붙여넣으세요.
2

오른쪽 위 도우미 아이콘 확인

확장 프로그램 아이콘에서 부산 K-Stat 도우미를 열어요.

실제 크롬 화면 일부 · 빨간 표시 위치
3

K-Stat 열기 → 연월 입력

도우미에서 K-Stat 열기 → 연도·월 → 새 작업 시작

확장 프로그램 버튼 위치 예시
4

지역·기간·정렬 확인

아래 항목과 실제 조회표를 비교한 뒤 체크하세요.

지역코드60 · 부산
국가수출·수입 MTI2: 전체 / 중국 MTI3: CN
조회기간당월 / 금년누계 / 전년누계
정렬수출금액 또는 수입금액 · 내림차순
K-Stat에 지역코드 60을 입력하면 화면의 ‘전국’ 글자를 ‘부산’으로 보정합니다. 안전하게 보정할 수 없으면 지역칸 아래에 안내문이 나옵니다. 실제 조회 결과도 확인하세요.
5

체크 → 엑셀다운 × 9회

결과를 확인해 체크하고 엑셀다운. 다음 조건은 자동 조회돼요.

수출 MTI2 3회 + 수입 MTI2 3회 + 중국 수입 MTI3 3회
6

9개 엑셀 선택해서 사이트로 보내기

보고서 사이트로 가져오기 → 다운로드한 엑셀 9개 선택 → 전달

폴더 권한을 열 필요는 없어요.
7

본부 엑셀 1개 추가

보고서 작성에서 본부 엑셀을 선택해요. K-Stat 9개는 전달된 상태예요.

추가한 본부 엑셀 1개와 K-Stat 9개를 확인
8

한글 보고서 생성하기

한글 보고서 생성하기 클릭 → HWPX 다운로드. 필요 시 검증 항목만 열어 확인

틀린 조건이나 필수 품목 누락이 있으면 이유를 표시해요.

예시 화면과 크롬 버전에 따라 버튼 위치가 조금 다를 수 있습니다. K-Stat 지역코드가 60이면 부산입니다. 화면 글자가 보정되더라도 실제 결과표를 확인한 뒤 체크하세요.   보고서 작성 바로가기
