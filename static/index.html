처음 사용하는 분만 도우미 설치

구글 크롬(Chrome)에서만 사용할 수 있습니다. 한 번 설치한 뒤에는 다시 설치하지 않아도 됩니다.

1 오른쪽 위 ‘개발자 모드’ 켜기

크롬 주소창에 chrome://extensions 입력 → 오른쪽 위 개발자 모드 켜기

2 왼쪽 위 ‘압축해제된 확장 프로그램 로드’

먼저 내려받은 ZIP 압축을 풀고 → 왼쪽 위 버튼 → 압축 푼 폴더 선택

도우미 다운로드 (ZIP) 크롬 확장 프로그램 열기 링크가 열리지 않으면 주소를 복사해 크롬 주소창에 붙여넣으세요.
설치 후에는 크롬 오른쪽 위의 도우미 하나로 시작하세요.
도우미에서 K-Stat 열기 → 자료 조회 및 9개 다운로드 → 보고서 작성 페이지 자동 이동까지 연결됩니다.매 조회 결과 확인·다운로드, 본부 엑셀 선택, 보고서 생성 클릭은 사용자가 진행합니다.
