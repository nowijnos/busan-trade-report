부산지역 수출입동향 자동작성

엑셀 원자료를 업로드하면 기존 양식을 유지한 한글 보고서(HWPX) 검토본을 생성합니다.
수출·수입, 당월·누계, MTI 단위를 검증하고 확인되지 않은 숫자는 공란으로 유지하고, 분석이 필요한 문장은 [작성자 입력] 표시를 넣습니다.

사용 순서   ① 매월 기본 엑셀 업로드 → ② K-Stat 당월·누계·전년도 누계 업로드 → ③ 검증 및 생성 → ④ HWPX 다운로드 → ⑤ 한글에서 최종 검수.
자료는 HTTPS를 통해 비밀번호로 보호된 웹 서버로 전송되어 처리됩니다. 회사 보안정책을 확인하세요. 특정 원인·정성 해석 및 상위 품목 선정은 반드시 최종 검수해 주세요.
통계 원본 조회   K-Stat 품목별 지자체 수출입 바로가기 ↗
한국무역협회 공식 K-Stat 사이트에서 지역·품목·국가·기간과 당월/누계를 선택해 엑셀로 다운로드하세요.

01. 기본 보고서 엑셀

월별 원본 파일 1개가 필수입니다. 작성연월은 파일 내부에서 자동 인식합니다.
필수
부산 국내 수출입동향 보고서 · .xlsx

한국무역협회의 「국내_수출입동향보고서(YYYYMM)_부산.xlsx」 원본. 지역총괄, 3년간 월별, 전국지자체, MTI4, 국가, 대륙, 가공단계 등 시트가 포함된 엑셀입니다.

예: 2026년 10월 보고서 → 국내_수출입동향보고서(202610)_부산.xlsx
필수 · XLSX 1개

02. MTI 2단위 수출입 통계

K-Stat > 국내통계 > 품목별 지자체 수출입. 지역=부산, 품목=MTI 2단위, 화면=금액, 단위=US$. 수출·수입 열이 한 파일에 모두 포함됩니다.
추가 자료
① 작성 대상 연월 · 당월

작성 대상 월로 조회 후 당월/누계 = 당월을 선택해 다운로드. 당월 자료를 선택해 주세요.

10월 보고서: 2026년 10월 / 당월 / MTI2
예: K-Stat 엑셀(기본 이름).xls
② 작성 대상 연월 · 누계

작성 대상 월로 조회 후 당월/누계 = 누계를 선택합니다. 당해 연도 1~해당 월 누계 자료입니다.

10월 보고서: 2026년 10월 / 누계 / MTI2
금년도 누계용
③ 전년도 같은 월 · 누계

작성연도보다 1년 앞선 연도의 같은 월을 조회. 당월/누계 = 누계를 선택합니다. 이 파일의 오른쪽 연도 금액이 전년도 1~해당 월 누계입니다.

10월 보고서: 2025년 10월 / 누계 / MTI2
전년도 누계용

03. 중국 MTI 3단위 수입 통계

K-Stat > 국내통계 > 품목별 지자체 수출입. 지역=부산, 국가=중국, 품목=MTI 3단위, 정렬=수입금액, 화면=금액. 수입열만 사용합니다.
추가 자료
④ 중국 수입 · 작성 대상 연월 당월

국가=중국 설정 후 작성대상 연월의 당월 조회 결과. 당월 수입금액 순위로 정렬해 다운로드해 주세요.

10월 보고서: 중국 / MTI3 / 2026년 10월 / 당월
중국 수입 상위 품목 선정에 필요
⑤ 중국 수입 · 금년도 누계

국가=중국, 작성대상 연월, 누계. 금년도 1월부터 작성 대상 월까지 누계입니다.

10월 보고서: 중국 / MTI3 / 2026년 10월 / 누계
여러 개 선택 가능 · 2025년 연간 실적과 혼동 금지
⑥ 중국 수입 · 전년도 누계

국가=중국, 전년도 같은 월, 누계. 전년도 1월부터 작성 대상 월까지 누계입니다. 조회 화면이 상위 20개만 나오면 동일 조건의 추가 결과 파일도 함께 넣을 수 있습니다.

04. 생성 및 검증

파일명 대신 파일의 조회 조건과 총계를 확인합니다. 불일치 자료를 임의로 사용하지 않습니다.
추가 자료가 없어도 생성할 수 있지만 관련 표는 공란으로 남습니다.
자동 생성 범위와 한계 보기

각 통계자료 입력·상위 10개국 대륙별 재배치·가공단계 수입 구분·월별 그래프 갱신을 지원합니다. 기존 표의 행·열·셀 수는 변경하지 않습니다. 원인 분석이나 외부 조회가 필요한 내용은 기존 본문 문단에 [작성자 입력: ...]으로 표시하여 한글 파일에서 바로 편집할 수 있습니다. 확인 가능한 통계·순위·증감률 설명은 자동으로 작성합니다. MTI4 품목은 상위 순위와 주요 증감액 기준 후보를 자동 배치하며 사용자 검토가 필요합니다. 한컴오피스 페이지 수·줄바꿈은 기계적 무결성 검사를 넘어서 실제 열어 확인해야 합니다.

이 버전은 웹 서버에서 처리합니다. 업로드 파일은 서버 메모리에서 처리하고, 생성 결과는 일정 시간 후 삭제됩니다. 계정 비밀번호를 공유하지 마세요.
