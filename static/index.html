처음 사용하시나요?

처음 1회만 도우미를 설치하면 됩니다. 설치가 끝났으면 왼쪽 ① 사용방법을 눌러 바로 다음 과정부터 보세요.

도우미 다운로드 (ZIP)

처음 1회 설치

아래 두 가지만 하면 설치가 끝나요.

  1. 크롬 확장 프로그램 열기 → 화면 오른쪽 위 개발자 모드 켜기
  2. 왼쪽 위 압축해제된 확장 프로그램 로드 → 압축 푼 도우미 폴더 선택

설치가 끝났다면

다음부터는 설치를 다시 할 필요 없어요.

  1. 왼쪽 ① 사용방법 클릭
  2. K-Stat 열기 → 연월 입력 → 새 작업 시작 순서로 진행
설치 위치 안내: 개발자 모드는 오른쪽 위, ‘압축해제된 확장 프로그램 로드’는 왼쪽 위에 있습니다.
