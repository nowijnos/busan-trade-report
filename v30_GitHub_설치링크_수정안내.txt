v30은 K-Stat 페이지의 지역명 '전국' 표시 문제만 고친 크롬 도우미입니다.

[먼저 크롬 도우미 설치]
1. 부산_KStat_크롬도우미_v30_부산표시보정_안내문.zip 압축 해제.
2. chrome://extensions 에서 이전 v28 도우미 비활성화.
3. 개발자 모드 켜기 -> 압축해제된 확장 프로그램 로드 -> kstat_chrome_v30 폴더 선택.
4. 기존 K-Stat 탭을 반드시 새로고침. 이전 버전의 고정 안내문 제거.

[웹사이트 사용방법의 다운로드 링크도 v30으로 바꾸려면]
이 웹사이트 패치 ZIP을 압축 해제하고, GitHub 저장소 루트에 다음 2개 경로만 올리세요.
- static/guide.html
- static/downloads/busan-kstat-chrome-v30.zip

위 파일을 업로드하면 사용방법 페이지의 '크롬 도우미 다운로드'가 v30을 가리킵니다.
그 외 보고서 엔진, HWPX 템플릿, 기존 Excel 업로드·생성·그래프 파일은 업데이트하지 않습니다.

[지역명 표시 보정]
지역코드 60 및 국가코드가 확인된 경우에만, 지역 입력칸 오른쪽의 정확히 '전국'이라는 표시를 찾으면 화면에서만 '부산'으로 바꿉니다.
표시를 안전하게 식별할 수 없다면 원본은 그대로 두고 그 입력칸 바로 아래에 설명문을 표시합니다.
둘 다 상단 조회 폼을 가리는 고정 안내문이 아닙니다.
코드 60 = 부산이지만, 조회 결과 데이터가 정말 부산인지 사용자가 확인해야 합니다.
조건 설정·조회·9개 다운로드·보고서 생성 로직은 v28과 동일합니다.
