부산 K-Stat 크롬 도우미 v28 설치 및 사용

1. 반드시 Chrome에서 https://busan-trade-report.onrender.com/guide 을 여세요.
2. ZIP을 압축 해제하세요.
3. 크롬 주소창 chrome://extensions → 개발자 모드 켜기.
4. [압축해제된 확장 프로그램을 로드합니다] → kstat_chrome_v28 폴더 선택.
5. 이전 버전 v27은 비활성화하고 K-Stat 탭을 새로고침하세요.
6. 도우미 최상단 [K-Stat 열기] → 보고서 연월 입력 → [새 작업 시작·자동 조회].
7. 9단계 매번 지역 코드 60, 국가, MTI2/MTI3, 수출/수입 정렬, 기간, 결과표를 눈으로 확인 → 체크 → 엑셀다운.
   다운로드 완료되면 다음 조건을 자동 설정하고 조회까지 진행합니다.
   기본 자료: 부산 MTI2 수출 당월/금년누계/전년누계 3개,
   부산 MTI2 수입 당월/금년누계/전년누계 3개,
   중국 MTI3 수입 당월/금년누계/전년누계 3개.
8. [보고서 사이트로 가져오기] → 다운로드한 XLS 9개 직접 선택 → [사이트로 가져오기].
9. 웹사이트 [보고서 작성]에서 K-Stat 9개 선택 여부 확인 → 본부 엑셀 XLSX 선택 → [한글 보고서 생성하기].

참고
- 부산 지역코드가 60으로 적용돼도 K-Stat 원래 안내 문구가 전국으로 남을 수 있습니다.
  파란 안내 태그는 화면 오른쪽 아래에 작게 표시해 기존 조회 조건과 겹치지 않습니다.
  반드시 조회 결과가 부산 기준인지 직접 확인하세요.
- 100개씩 보기 설정은 화면 목록 수이며, 다운로드에 모든 MTI 코드가 포함된다는 보장은 없습니다.
  필수 품목이 파일에 없으면 웹사이트가 사유를 표시하고 생성을 중단합니다.
- 본부 HWPX 템플릿은 변경하지 않습니다.
- Chrome 확장 프로그램은 자동 설치되지 않습니다. 회사 보안지침을 지켜 주세요.
- K-Stat 로그인 정보/세션/쿠키를 수집하거나 서버로 보내지 않습니다.
