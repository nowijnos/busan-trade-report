부산지역 수출입동향 자동작성 v35 — 한글 그래프 글꼴 및 사용설명 개선

1. ZIP 압축 해제
2. 압축을 푼 내용물을 기존 GitHub 저장소 루트에 업로드 (static/static 중복 금지)
3. Commit changes, Render 배포 성공 확인, Ctrl+Shift+R

이번 수정 파일:
- engine.py : 한글 글꼴의 실제 한글 글리프 검사 + koreanize-matplotlib 패키지 글꼴 명시적 등록
- requirements.txt : 기존 koreanize-matplotlib 의존성 강조
- static/index.html : 도우미 하나로 K-Stat부터 보고서 작성까지 연결되는 장점 설명
- static/guide.html : 크롬 주소창 오른쪽의 도우미 아이콘 위치 및 한 번 설치 후 사용 흐름 설명
- static/assets/chrome-helper-icon-strip.jpg : 이용자가 제공한 실제 브라우저 사진 일부

중요: Render 대시보드 > 서비스 > Settings > Build Command가 'pip install -r requirements.txt'인지 확인하세요.
그렇지 않으면 koreanize-matplotlib이 설치되지 않아 한글 그래프 생성 오류가 남습니다.
수정 뒤 기존 Render 서비스에서 'Clear build cache & deploy'를 선택해 의존성을 새로 설치해 주세요.
