1. ZIP 압축을 풀고 안의 모든 파일과 폴더를 GitHub 저장소 최상위에 업로드.
2. 특히 chart_assets/glyph_atlas.png 와 glyph_metrics.json이 있어야 합니다.
   폴더 자체를 빠뜨리면 차트 생성 시 오류를 반환합니다.
3. GitHub에서 Commit changes. Render 배포가 성공해야 적용됩니다.
4. 기존 웹사이트 주소 뒤에 /health 접속 (인증 요구될 수 있음).
   'version':'v39-rasterized-chart-text' 확인.
5. 보고서를 새로 생성/다운로드 (이전에 받은 HWPX는 바뀌지 않습니다).
